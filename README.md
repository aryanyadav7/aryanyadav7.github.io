# Aryan Yadav Portfolio

Responsive static portfolio for GitHub Pages, built with HTML, CSS and vanilla JavaScript.

## Update the existing site
Copy the contents of this folder into the root of `aryanyadav7.github.io`, then run:

```bash
git add .
git commit -m "Redesign portfolio and add contact form"
git push
```

## Contact form
The form uses FormSubmit and sends to `aryanyadav0700@gmail.com`. Since this is a static GitHub Pages site, the form provider handles email delivery. On first submission, FormSubmit may send an activation email to the destination address; click its confirmation link, then test the form again. The form has a honeypot field and captcha enabled. Never put email passwords or private SMTP credentials in this public repository.

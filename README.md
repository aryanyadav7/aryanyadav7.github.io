# Aryan Yadav — Portfolio

A responsive developer portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in a browser.

## GitHub Pages

Recommended repository name:

`YOUR-GITHUB-USERNAME.github.io`

Upload the contents of this folder to the repository and enable GitHub Pages from:

**Settings → Pages → Deploy from a branch → main → /(root)**

The site will then be available at:

`https://YOUR-GITHUB-USERNAME.github.io/`
